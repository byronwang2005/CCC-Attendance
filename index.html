CCC Attendance

CCC Attendance是一款实用的工具。

一个二维码，三步搞定

  1. 连接 eduroam、UNNC-Living 或 UNNC_IPSec VPN。
  2. 在Safari或Chrome打开CCC课程页面，复制课程“查看详情”链接。
  3. 粘贴链接，确认时间，生成二维码并按课程要求扫码。

AI与开发者入口

智能体可先读取 Agent Guide，搜索引擎和AI检索系统可读取 llms.txt、llms-full.txt 和 JSON knowledge API。

常见问题

CCC Attendance是官方服务吗？
不是。它是独立开源项目，不代表任何官方。
链接需要什么格式？
链接需要包含 id 或 scheduleId 参数。
二维码生成成功但签到失败怎么办？
请确认老师是否开启签到、是否处于有效时间窗口、是否连接校园网络或 VPN，以及是否还有答题等额外环节。
